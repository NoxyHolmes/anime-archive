# 🐉 Аниме-Архив

Персональный каталог просмотренных аниме с тирами, статистикой, календарём просмотра и настраиваемыми анимированными фонами.

## 🔗 Быстрые ссылки

- **🌐 Публичная версия (просмотр):** https://noxyholmes.github.io/anime-archive/
- **👑 Режим владельца (редактирование):** https://noxyholmes.github.io/anime-archive/admin.html

> ⚠️ Ссылку на режим владельца храните приватно — она даёт полный доступ к редактированию.

## 📸 Возможности

- 7 тиров (SSS → E) с 3D-анимированными буквами и уникальными цветами
- Drag & Drop карточек внутри тиров и между ними (работает на тач-экранах)
- Статистика на Chart.js: жанры, распределение по тирам, динамика по месяцам
- Календарь просмотра с сеткой и списковым видом
- 20 пресетов фоновой анимации (сакура, снег, звёзды, сердечки и др.)
- Тёмная/светлая тема, кастомный акцентный цвет
- Автосохранение в localStorage + синхронизация с GitHub через API
- Импорт/экспорт JSON для бэкапа
- Полная мобильная адаптация

## 🔑 Настройка режима владельца

1. Откройте ссылку администратора: https://noxyholmes.github.io/anime-archive/admin.html
2. Нажмите кнопку ** GitHub** в шапке
3. Создайте Personal Access Token на https://github.com/settings/tokens/new (права `repo`)
4. Введите токен и имя репозитория (`noxyholmes/anime-archive`)
5. Нажмите **Сохранить конфигурацию**

Теперь все изменения будут автоматически коммититься в репозиторий.
